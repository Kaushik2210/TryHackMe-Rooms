# TryHackMe Write-Ups

Concept guides for 50 completed TryHackMe rooms — technical deep-dives on the mechanisms, tools, and
defenses each room covers, written from public documentation and reference material.

> **These are concept guides, not personal walkthroughs.** Each article covers what the room teaches —
> protocol internals, tool syntax, defensive analysis — sourced from RFCs, vendor docs, and standards
> bodies. They do not include personal session evidence (screenshots, captured command output, or
> room-specific answers), since that evidence hasn't been captured yet. See
> [`_data/completed-rooms.md`](_data/completed-rooms.md) for open items, including per-room dates and
> URLs still to be filled in, and [`templates/PIPELINE.md`](templates/PIPELINE.md) for how a room
> upgrades from concept guide to full evidence-backed write-up once notes/screenshots exist.

## How this repo works

See [`templates/PIPELINE.md`](templates/PIPELINE.md) for the processing pipeline and quality gate.
Concept guides upgrade to full evidence-backed write-ups (methodology, findings, answer key) once
per-room notes and screenshots are added to `_incoming/<room-slug>/`.
